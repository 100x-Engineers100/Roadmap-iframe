## TODO — What's Left

### 1. Email Cron Job (most important — emails won't send without this)
The `send-reminders` function works but nothing calls it automatically.
Need to set up a pg_cron job in Supabase to POST to it every hour.

**How to set it up:**
Go to Supabase Dashboard → SQL Editor, run:
```sql
select cron.schedule(
  'send-reminders-hourly',
  '0 * * * *',
  $$
  select net.http_post(
    url := 'https://oxzbnhssdnmvbfmuirbf.supabase.co/functions/v1/send-reminders',
    headers := '{"Authorization": "Bearer <SERVICE_ROLE_KEY>", "Content-Type": "application/json"}'::jsonb,
    body := '{}'::jsonb
  );
  $$
);
```
Replace `<SERVICE_ROLE_KEY>` with the actual key from `.env`.

Alternatively can use Supabase Dashboard → Integrations → Cron Jobs UI.
