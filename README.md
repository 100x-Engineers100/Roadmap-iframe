# 100x AI Roadmap Builder — HLD

## Goal

Generate a personalized AI learning roadmap for any user based on their goal, background, and constraints. Output is a visual HTML roadmap stored in cloud + delivered via email reminders.

---

## Input → Processing → Output

### INPUT

User submits intake form via frontend:

| Field | Example |
|---|---|
| `goal` | "Become an AI engineer" |
| `background_role` | "Frontend developer" |
| `experience_years` | "2 years" |
| `weak_areas` | ["RAG", "agents"] |
| `hours_per_week` | "10" |
| `learning_style` | "project-based" |
| `timeframe_months` | 3 |

Request hits `POST /generate` (Supabase Edge Function) with JWT bearer token.

---

### PROCESSING

```
1. AUTH
   JWT → Supabase anon client → extract user_id, email, display_name
   Rate limit: max 2 roadmaps / 24h per user

2. DB SETUP
   Upsert → users table
   Insert  → intake_answers table
   Insert  → roadmaps table (status: "pending")
   Return  → { roadmap_id, status: "generating" } immediately (non-blocking)

3. BACKGROUND GENERATION (EdgeRuntime.waitUntil)

   [A] ZENO MCP CALL
       POST goal + background + weak_areas + timeframe → internal Zeno server
       Returns: course overview + topic index + evidence[] (KB excerpts)

   [B] PROMPT BUILD
       User profile + Zeno overview + topic index + top 8 evidence excerpts
       → single structured user message

   [C] LLM CALL (GPT-4.1-mini via OpenAI SDK)
       System prompt: spine-and-cluster roadmap architect
       Domain pools: VISUAL_AI | LLM_FULLSTACK | AGENTS_PRODUCTION
       response_format: json_object | temp: 0.3 | max_tokens: 12000
       Output: roadmap JSON (spine nodes, clusters, checkpoints, coaching, reminder emails)
       Validation: Zod schema (RoadmapSchema) — auto-retry once on failure

   [D] RENDER
       renderRoadmapHTML(roadmap) → styled HTML visual roadmap

4. STORAGE
   Upload HTML → Supabase Storage bucket: roadmaps/{user_id}/{roadmap_id}.html
   Get public URL

5. DB UPDATE
   Insert → roadmap_revisions (versioned JSON history)
   Update → roadmaps: status="complete", roadmap_json, svg_url=public HTML URL

6. REMINDER SCHEDULING
   Insert 2 rows → reminders table
   - day_3: scheduled_at = now + 3 days
   - day_6: scheduled_at = now + 6 days
   (email subject + body generated by LLM inside roadmap_json.reminder_emails)
```

---

### OUTPUT

**Immediate (sync):**
- Frontend polls `GET /status?roadmap_id=...`
- Status: `pending → generating → complete`
- On complete: renders `svg_url` in iframe

**Async (email):**
- `send-reminders` edge function runs on cron schedule
- Queries `reminders` where `status=pending` AND `scheduled_at <= now`
- Pulls subject + body from `roadmap_json.reminder_emails[reminder_type]`
- Sends via Resend API from `roadmap@100xengineers.com`
- Updates reminder row: `status=sent` or `status=failed`

## Stack

| Layer | Tech |
|---|---|
| Frontend | Next.js (iframe embed) |
| Edge Functions | Deno / Supabase Edge Runtime |
| Auth | Supabase Auth (JWT) |
| Database | Supabase Postgres |
| Storage | Supabase Storage |
| LLM | OpenAI GPT-4.1-mini |
| Knowledge Base | Zeno MCP (internal) |
| Email | Resend |

---

## DB Tables

- `users` — auth profile
- `intake_answers` — raw user input per generation
- `roadmaps` — roadmap status, json, storage URL
- `roadmap_revisions` — versioned history of roadmap JSON
- `reminders` — scheduled day_3 / day_6 email jobs
